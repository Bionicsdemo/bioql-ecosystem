# Visualization Types Reference

## Quick Visual Guide to Generated Plots

This reference shows examples of each visualization type generated by the system.

---

## Base Visualizations (All Molecule Types)

### 1. Energy Histogram
**Purpose:** Display VQE energy distribution across quantum states
**File:** `{job_id}_energy_histogram.png`
**Format:** Bar chart with probability-colored bars
**X-axis:** State Index
**Y-axis:** Energy (Hartree or arbitrary units)
**Features:**
- Ground state reference line (if available)
- Probability annotations on bars
- Color gradient by measurement frequency

**Example Output:**
```
Energy (Ha)
    ^
-5  |  ████       Ground state line
-4  |  ██
-3  |    ████
-2  |      ██
-1  |        ████
    +----------------------> State Index
```

---

### 2. State Distribution
**Purpose:** Show quantum measurement count distribution
**File:** `{job_id}_state_distribution.png`
**Format:** Bar chart
**X-axis:** Quantum State (bitstring)
**Y-axis:** Measurement Counts
**Features:**
- Top 15 most frequent states
- Value labels on bars
- Rotated state labels for readability

---

### 3. Interactive Plot
**Purpose:** Interactive exploration of quantum states
**File:** `{job_id}_interactive.html`
**Format:** Plotly HTML (fully interactive)
**Features:**
- Zoom/pan capabilities
- Hover tooltips with data
- Color scale by count
- Can be embedded in web apps

---

### 4. Energy Landscape
**Purpose:** Molecular potential energy surface
**File:** `{job_id}_energy_landscape.png`
**Format:** Line plot with markers
**X-axis:** Parameter Space / Bond Distance Index
**Y-axis:** Energy (Hartree)
**Features:**
- Ground state reference line
- Global minimum marked with red star
- Local maximum with orange triangle
- Energy range annotation
- Filled area under curve

---

### 5. Hamiltonian Visualization
**Purpose:** Molecular Hamiltonian structure analysis
**File:** `{job_id}_hamiltonian_viz.png`
**Format:** Dual panel (bar chart + pie chart)
**Left Panel:** Energy spectrum across states
**Right Panel:** Pauli operator distribution
**Features:**
- Color-coded by energy
- Operator decomposition (X, Y, Z, XX, YY, ZZ, etc.)
- Term count statistics

---

### 6. VQE Convergence
**Purpose:** Optimization history and convergence
**File:** `{job_id}_vqe_convergence.png`
**Format:** Dual panel (linear + log scale)
**Top Panel:** Energy vs iteration
**Bottom Panel:** Error deviation (log scale)
**Features:**
- Final energy marked with red star
- Exact ground state reference (if known)
- Convergence metrics box
- Average convergence rate

---

## Small Molecule Visualizations

### 7. Molecular Orbitals
**Purpose:** HOMO-LUMO energy diagram
**File:** `{job_id}_molecular_orbitals.png`
**Format:** Energy level diagram
**Features:**
- Color-coded orbitals:
  - Red: Occupied
  - Teal: HOMO
  - Mint: LUMO
  - Light blue: Virtual
- HOMO-LUMO gap with double arrow
- Gap shown in both Hartree and eV
- Energy values labeled

**Example:**
```
Energy (Ha)
    ^
+2  |  ──────  LUMO (virtual)
    |    ↕ Gap: 3.5 Ha (95 eV)
-1  |  ──────  HOMO (occupied)
-3  |  ──────  Occupied
-5  |  ──────  Occupied
```

---

### 8. Electron Density
**Purpose:** Visualize electron probability distribution
**File:** `{job_id}_electron_density.png`
**Format:** Dual panel (2D contour + 3D surface)
**Left:** 2D contour map with levels
**Right:** 3D surface plot
**Units:** Electron density in atomic units (a.u.)
**Features:**
- Quantum state-seeded patterns
- Multiple Gaussian centers
- Color maps: 'hot' (2D), 'plasma' (3D)

---

### 9. Bond Energy Analysis
**Purpose:** Bond dissociation and energy decomposition
**File:** `{job_id}_bond_energy.png`
**Format:** Dual panel
**Left:** Bond dissociation curve (Morse potential)
**Right:** Energy decomposition (horizontal bar chart)
**Features:**
- Equilibrium distance marked with red star
- Energy components:
  - Kinetic energy
  - Nuclear attraction
  - Electron repulsion
  - Exchange-correlation
  - Total energy

---

## Protein Visualizations

### 10. Secondary Structure
**Purpose:** Predict helix/sheet/coil regions
**File:** `{job_id}_secondary_structure.png`
**Format:** Dual panel (stacked area + ribbon)
**Top:** Probability distribution (stacked area)
**Bottom:** Structure ribbon representation
**Colors:**
- Red: α-Helix
- Teal: β-Sheet
- Light gray: Coil/Loop
**Features:**
- Per-residue probabilities
- Color-coded ribbon segments
- Structure segment labels

---

### 11. Protein Folding
**Purpose:** Folding energy landscape
**File:** `{job_id}_protein_folding.png`
**Format:** Triple panel
**Left:** 3D folding pathway (helical)
**Middle:** Energy funnel diagram
**Right:** Free energy profile
**Features:**
- Unfolded (green circle) → Folded (red star)
- Energy funnel with gradient
- Transition states marked with red triangles
- Intermediates marked with green circles
- Energy in kcal/mol

---

### 12. Ramachandran Plot
**Purpose:** Validate backbone dihedral angles
**File:** `{job_id}_ramachandran.png`
**Format:** 2D histogram + scatter plot
**X-axis:** Φ (phi) angles (-180° to +180°)
**Y-axis:** Ψ (psi) angles (-180° to +180°)
**Features:**
- Density heatmap background
- Individual residue points
- Favored regions marked:
  - Red box: α-Helix region
  - Green box: β-Sheet region
- Colorbar showing density

---

## DNA/RNA Visualizations

### 13. Double Helix
**Purpose:** 3D structure of nucleic acid
**File:** `{job_id}_double_helix.png`
**Format:** 3D plot with strands and base pairs
**Features:**
- Two antiparallel strands (blue and red)
- Base pair rungs color-coded:
  - A: Red
  - T/U: Teal
  - G: Yellow
  - C: Mint
- Base pair labels every 2 pairs
- Realistic B-DNA geometry:
  - Radius: 10 Å
  - Pitch: 34 Å
  - Rise: 3.4 Å per bp

---

### 14. Base Pair Analysis
**Purpose:** Stacking energies and H-bonding
**File:** `{job_id}_base_pairs.png`
**Format:** Dual panel (bar chart + pie chart)
**Left:** Base pair stacking energies (kcal/mol)
**Right:** A-T vs G-C composition
**Features:**
- Experimentally derived stacking energies
- Color-coded by energy strength
- GC content percentage
- Total H-bond count
- Energy range: -6 to -11 kcal/mol

---

### 15. Groove Width
**Purpose:** Major and minor groove measurements
**File:** `{job_id}_groove_width.png`
**Format:** Dual panel (line plot + histogram)
**Left:** Width along sequence
**Right:** Width distribution
**Features:**
- Major groove: ~22 Å (purple)
- Minor groove: ~12 Å (cyan)
- Reference lines for ideal widths
- Filled areas showing deviation
- Statistics box (mean, std)

---

## Metabolite Visualizations

### 16. Metabolic Pathway
**Purpose:** Network graph of metabolic reactions
**File:** `{job_id}_metabolic_pathway.png`
**Format:** Graph with nodes and edges
**Nodes:** Metabolites (circles, color-coded)
**Edges:** Reactions (arrows with enzyme labels)
**Features:**
- Branch point identification
- Pathway flow direction
- Enzyme labels in yellow boxes
- Main pathway + branches
- Equal aspect ratio for clarity

**Example:**
```
  M1 ──E1──> M2 ──E2──> M3
              |
              E3
              ↓
             M4 ──E4──> M5
```

---

### 17. Reactivity Analysis
**Purpose:** Chemical reactivity and reaction profiles
**File:** `{job_id}_reactivity.png`
**Format:** Quad panel layout
**Top-Left:** Electrophilic/nucleophilic sites (scatter)
**Top-Right:** HOMO-LUMO frontier orbitals (bar)
**Bottom-Left:** Reaction energy profile (line)
**Bottom-Right:** (Reserved for future use)
**Features:**
- Partial charge map (RdBu colormap)
- E+ and Nu- site labels
- HOMO-LUMO gap in eV
- Activation energy (Ea) annotation
- Transition state identification
- Energy in kcal/mol

## Report Files

### 18. Scientific Report (TXT)
**Purpose:** Human-readable comprehensive report
**File:** `{job_id}_report.txt`
**Sections:**
1. Job Information
2. VQE Algorithm Details
3. Quantum Execution Statistics
4. IBM Quantum Hardware Details
5. Scientific Validation & Quality Metrics
6. Generated Visualizations

**Features:**
- Energy in multiple units (Ha, eV, kcal/mol)
- State distribution statistics (entropy, probability)
- Quality score (0-100)
- Recommendations
- Validation checks

## Color Schemes

### Scientific Standards

**Energy Levels:**
- Low energy: Blue/Purple
- High energy: Red/Orange
- Gradients: Viridis, Plasma, Coolwarm

**Molecular Components:**
- Occupied orbitals: #FF6B6B (Red)
- HOMO: #4ECDC4 (Teal)
- LUMO: #95E1D3 (Mint)
- Virtual: #C7CEEA (Light blue)

**Protein Structures:**
- α-Helix: #FF6B6B (Red)
- β-Sheet: #4ECDC4 (Teal)
- Coil/Loop: #C7CEEA (Light gray)

**DNA/RNA Bases:**
- Adenine: #FF6B6B (Red)
- Thymine/Uracil: #4ECDC4 (Teal)
- Guanine: #FFE66D (Yellow)
- Cytosine: #95E1D3 (Mint)

## Plot Specifications

**General:**
- DPI: 300 (publication quality)
- Figure sizes: 10x6 to 16x12 inches
- Font sizes: 9-16pt
- Line widths: 1-4pt
- Grid: alpha=0.3, dotted
- Background: #f8f9fa (light gray)

**Text Elements:**
- Title: 14-16pt, bold
- Axis labels: 12-14pt, bold
- Tick labels: 9-11pt
- Annotations: 8-10pt
- Legends: 10-11pt

## Usage Tips

1. **File naming:** All files include job_id for easy tracking
2. **Batch generation:** Multiple molecule types can be processed in parallel
3. **Storage:** Store in organized directory structure by molecule type
4. **Sharing:** PNG files ready for presentations, HTML for interactive sharing
5. **Reproducibility:** JSON reports contain all parameters for reproduction

## Integration Examples

### With Jupyter Notebooks
```python
from IPython.display import Image, HTML

# Display static plot
Image(files['molecular_orbitals'])

# Display interactive plot
HTML(filename=files['interactive'])
```

### With Web Applications
```html
<!-- Embed interactive plot -->
<iframe src="job_123_interactive.html" width="100%" height="600px"></iframe>

<!-- Display static image -->
<img src="job_123_energy_histogram.png" width="800px">
```

```latex
\begin{figure}[h]
  \centering
  \includegraphics[width=0.8\textwidth]{job_123_molecular_orbitals.png}

  \label{fig:mo}
\end{figure}
```
