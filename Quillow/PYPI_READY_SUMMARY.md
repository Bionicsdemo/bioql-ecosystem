## 🔑 Key Architecture Decisions

### 1. **Standalone Package**
- ✅ Quillow is **independent** from BioQL
- ✅ Users install with: `pip install quillow`
- ✅ No `bioql` dependency in `install_requires`
- ✅ BioQL integration via REST API only

### 2. **Shared Authentication**
- ✅ Uses same API keys as BioQL server
- ✅ API key format: `__BIOQL_REDACTED__`
- ✅ Generated by: `/Users/heinzjungbluth/Desktop/Server_bioql/auth_server/bioql_auth_server_stripe.py`
- ✅ Connects to: `https://api.bioql.bio`

### 3. **API Integration**
Quillow communicates with BioQL via REST endpoints:
- `/auth/validate` - Validate API key
- `/billing/check-limits` - Check quota
- `/billing/record-usage` - Record QEC usage
- `/quantum/execute` - Execute circuits on real hardware

### 4. **Billing Transparency**
QEC overhead automatically tracked:
- **d=3**: 1.2x cost (20% overhead)
- **d=5**: 1.5x cost (50% overhead)
- **d=7**: 2.0x cost (100% overhead)


## 👥 User Experience

### Installation

```bash
# Basic installation
pip install quillow

# With GPU support
pip install quillow[gpu]

# All features
pip install quillow[all]
```

### Configuration

Users get their API key from BioQL:

```bash
# 1. Sign up at bioql.bio
# 2. Get API key: __BIOQL_REDACTED__
# 3. Configure Quillow

export BIOQL_API_KEY="__BIOQL_REDACTED__"
```

### Usage

```bash
# Check connection
quillow check-bioql

# Run simulation
quillow simulate -d 5 -s 10000

# Protect BioQL query with QEC
quillow protect-bioql \
  --query "optimize H2 molecule" \
  --backend ibm_torino \
  --shots 2048
```

### Python API

```python
from backends.bioql_backend import BioQLOptimizer

# Initialize (reads BIOQL_API_KEY from env)
optimizer = BioQLOptimizer(qec_distance=5)

# Execute with QEC protection
result = optimizer.execute_with_qec(
    bioql_query="apply VQE to aspirin",
    backend="ibm_torino",
    shots=2048
)

print(f"Energy: {result['energy']:.6f} Hartree")
print(f"Logical Error Rate: {result['logical_error_rate']:.6f}")
```

## 🔐 Security Notes

### API Key Security

**Users should**:
- ✅ Never commit API keys to git
- ✅ Use environment variables or config files
- ✅ Rotate keys periodically
- ✅ Keep keys in `~/.quillow/config.yaml` with `chmod 600`

**Server validates**:
- ✅ API key format: `bioql_*`
- ✅ User existence in database
- ✅ Account balance > 0
- ✅ Quota limits
