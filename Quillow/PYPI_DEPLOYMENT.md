# Quillow PyPI Deployment Guide

## Overview

Quillow is a **standalone Python package** completely independent from BioQL. Users install it separately with `pip install quillow`, but it integrates seamlessly with BioQL using the same API keys generated by the BioQL authentication server.

## Architecture

```
┌─────────────────────────────────────────────────────┐
│  User's Computer                                     │
│                                                      │
│  pip install quillow  (separate from bioql)         │
│  ├── Quillow QEC System                             │
│  ├── Surface Codes (d=3,5,7)                        │
│  ├── MWPM Decoder                                   │
│  └── BioQL API Client                               │
│                                                      │
│  export BIOQL_API_KEY="bioql_XXXX..."               │
│                                                      │
│  quillow protect-bioql --query "..."                │
│         │                                            │
└─────────┼────────────────────────────────────────────┘
          │
          │ HTTPS (API Key: bioql_XXXX...)
          ↓
┌─────────────────────────────────────────────────────┐
│  api.bioql.bio (Server)                              │
│                                                      │
│  ├── /auth/validate (validate API key)              │
│  ├── /billing/check-limits (check quota)            │
│  ├── /billing/record-usage (record with QEC cost)   │
│  └── /quantum/execute (run on real hardware)        │
│                                                      │
│  Returns: Quantum results                           │
└─────────────────────────────────────────────────────┘
```

### Configuration

Users configure their BioQL API key:

```bash
# Option 1: Environment variable
export BIOQL_API_KEY="__BIOQL_REDACTED__"

# Option 2: Config file (~/.quillow/config.yaml)
mkdir -p ~/.quillow
cat > ~/.quillow/config.yaml << EOF
bioql:
  api_key: __BIOQL_REDACTED__
  base_url: https://api.bioql.bio
qec:
  default_distance: 5
  enable_by_default: true
EOF

# Option 3: Pass directly in code
from backends.bioql_backend import BioQLBackend, BioQLConfig

config = BioQLConfig(api_key="__BIOQL_REDACTED__")
backend = BioQLBackend(config)
```

### Usage Examples

#### CLI Usage

```bash
# Check BioQL connection
quillow check-bioql

# Run simulation
quillow simulate -d 5 -s 10000 --decoder pymatching

# Protect BioQL query with QEC
quillow protect-bioql \
  --query "optimize H2 molecule with VQE" \
  --backend ibm_torino \
  --shots 2048 \
  --qec-distance 5

# Benchmark thresholds
quillow benchmark threshold --distances 3,5,7
```

#### Python API Usage

```python
from backends.bioql_backend import BioQLOptimizer

# Initialize (reads BIOQL_API_KEY from environment)
optimizer = BioQLOptimizer(qec_distance=5)

# Execute quantum chemistry calculation with QEC protection
result = optimizer.execute_with_qec(
    bioql_query="apply VQE to ibuprofen molecule",
    backend="ibm_torino",
    shots=2048
)

print(f"Energy: {result['energy']:.6f} Hartree")
print(f"Logical Error Rate: {result['logical_error_rate']:.6f}")
print(f"QEC Improvement: {abs(result['raw_energy'] - result['energy']):.6f}")
```

#### Direct Backend Usage

```python
from backends.bioql_backend import BioQLBackend, BioQLConfig
import stim

# Configure
config = BioQLConfig(
    api_key="__BIOQL_REDACTED__",
    base_url="https://api.bioql.bio"
)

# Initialize backend
backend = BioQLBackend(config, qec_distance=5)

# Validate API key
if backend.validate_api_key():
    print("✅ API key valid")

# Check quota
quota = backend.check_quota()
print(f"Remaining balance: ${quota['balance']:.2f}")

# Execute circuit
circuit = stim.Circuit("""
    H 0
    CNOT 0 1
    M 0 1
""")

result = backend.execute(circuit, shots=1024, backend="simulator")
print(f"Logical error rate: {result.metadata['logical_error_rate']:.6f}")
```

## Billing Integration

Quillow automatically records usage with the BioQL billing system:

```python
# In bioql_backend.py
def _record_usage(self, shots: int, backend: str, qec_overhead: float = 1.0):
    """Record usage with BioQL billing."""
    # Calculate cost with QEC overhead
    base_cost = shots * 0.001  # $0.001 per shot
    qec_cost = base_cost * qec_overhead

    payload = {
        "api_key": self.config.api_key,
        "shots": shots,
        "backend": backend,
        "qec_enabled": self.enable_qec,
        "qec_distance": self.qec_distance,
        "qec_overhead_multiplier": qec_overhead,
        "total_cost_usd": qec_cost
    }

    requests.post(f"{self.config.base_url}/billing/record-usage", json=payload)
```

**QEC Overhead Multipliers**:
- d=3: 1.2x cost (20% overhead)
- d=5: 1.5x cost (50% overhead)
- d=7: 2.0x cost (100% overhead)

## Troubleshooting

### Error: "Package name already taken"

If `quillow` is already taken on PyPI, choose alternative:
- `quillow-qec`
- `bioql-quillow`
- `spectrix-quillow`

### Error: "Invalid authentication credentials"

```bash
# Verify token
echo $TWINE_PASSWORD

# Re-generate token at https://pypi.org/manage/account/token/
```

### Error: "File already exists"

You cannot replace an existing version. Increment version number and re-upload.

### Error: "README not rendering"

Ensure `long_description_content_type='text/markdown'` in `setup.py`.

Test locally:
```bash
python -m readme_renderer README.md -o /tmp/test.html
open /tmp/test.html
```

## Continuous Integration

Consider setting up CI/CD with GitHub Actions (`.github/workflows/publish.yml`):

```yaml
name: Publish to PyPI

on:
  release:
    types: [published]

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-python@v4
        with:
          python-version: '3.10'
      - name: Install dependencies
        run: |
          pip install build twine
      - name: Build
        run: python -m build
      - name: Publish
        env:
          TWINE_USERNAME: __token__
          TWINE_PASSWORD: ${{ secrets.PYPI_TOKEN }}
        run: twine upload dist/*
```
