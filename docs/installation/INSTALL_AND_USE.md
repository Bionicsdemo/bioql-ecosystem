## 📚 Example Usage

### Example 1: Surface Code Simulation

**Input** (in chat):
```
@bioql Run surface code with distance 5 using stim backend, 1000 shots
```

**Output**:
```python
#!/usr/bin/env python3
"""
Surface Code Simulation - Distance 5
============================================
Generated by BioQL Quillow Integration v1.0.0

Configuration:
- Distance: 5
- Physical qubits: 41
- Logical qubits: 1
- Backend: stim
- Shots: 1000
"""

import os
from bioql import quantum
import numpy as np

# Configuration
api_key = os.getenv('BIOQL_API_KEY', '__BIOQL_REDACTED__')
distance = 5
shots = 1000
backend = 'stim'

print("=" * 80)
print("🔬 QUILLOW Surface Code Simulation")
print("=" * 80)

result = quantum(
    f"Simulate surface code with distance {distance} for quantum error correction. "
    f"Initialize logical |0⟩ state, apply noisy operations, "
    f"perform syndrome measurement, decode using minimum-weight perfect matching.",
    backend=backend,
    shots=shots,
    api_key=api_key,
    qec_config={
        'enabled': True,
        'type': 'surface_code',
        'distance': distance,
        'logical_qubits': 1
    }
)

print(f"\n{result}\n")
```

**Cost**: $0.15 (1000 shots × d=5 multiplier)

### Example 2: Quantum Chemistry with QEC

**Input**:
```
@bioql Simulate H2 molecule with quantum error correction distance 3
```

**Output**:
```python
#!/usr/bin/env python3
"""
Quantum Chemistry with QEC - H2 Molecule
===============================================
"""

import os
from bioql import quantum

api_key = os.getenv('BIOQL_API_KEY', '__BIOQL_REDACTED__')
molecule = 'H2'
distance = 3
shots = 1000
backend = 'simulator'

print("🧬 BioQL Quantum Chemistry + Quillow QEC")

result = quantum(
    f"Calculate ground state energy of {molecule} molecule using VQE with "
    f"quantum error correction (surface code distance {distance}). "
    f"Use UCCSD ansatz and optimize with COBYLA.",
    backend=backend,
    shots=shots,
    api_key=api_key,
    qec_config={
        'enabled': True,
        'type': 'surface_code',
        'distance': distance
    }
)

print(f"\n{result}\n")

if isinstance(result, dict) and 'energy' in result:
    print(f"✅ Ground State Energy: {result['energy']:.6f} Hartree")
```

**Cost**: $0.10 (1000 shots × d=3 multiplier)
